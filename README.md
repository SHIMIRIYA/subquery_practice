# College Database – SQL Assignment

## About the Project
This project contains 12 SQL assignment questions solved using MySQL with the College Database.

## Topics Covered
- Subqueries
- Aggregate Functions (AVG, MAX)
- IN and NOT IN
- ANY and ALL
- IS NOT NULL
- GROUP BY
- HAVING
- Comparison Operators

## Assignment Details
A total of 12 SQL questions were completed to practice database querying and data analysis using student, course, and enrollment tables.

## Objective
To improve SQL query-writing skills and understand how to retrieve, filter, compare, and analyze data using MySQL.

## Tools Used
- MySQL
- MySQL Workbench

## Status
Completed – 12 Questions

## Description
This assignment was completed as part of SQL learning and practice to develop practical database management and querying skills.
